03 / SELECT

Select

触发器就是宿主本身（role="combobox"），选项是光 DOM 里的 <sf-option>。支持上下键 / Home / End / Enter，放不下会自动翻到上方。

04 / MULTISELECT

MultiSelect

选中不关列表（要连选），已选项变成 chip，回车在已选项上是取消。表单值是多个同名条目，所以提交时是数组。

已选 React TypeScript CSS Node

05 / CHECKBOX

Checkbox

视觉是 shadow 里的方块，行为仍是原生 checkbox：空格切换、读屏角色、半选态都由浏览器给。

state 未选 已选 半选 禁用 选中禁用
06 / RADIO

Radio

原生 radio 只在同一棵 DOM 树里互斥，每个组件各有 shadow root 就连不成一组，所以按 name 自己维护分组表；方向键在组内移动也一并实现了。

07 / SWITCH

Switch

用 role="switch" 而不是 checkbox —— 开关不是"打勾"，读屏该听到的是"开/关"。文字包在按钮里，整块可点。

state 接收通知 接收通知 禁用
08 / SLIDER

Slider

原生 range 负责拖动和键盘，外观自己画：已填充那段用渐变做，百分比由 JS 写进内部变量 --_pct。

show-value

disabled

Field

label + 必填星号 + 说明 + 错误。它不管控件的值，只管"围绕控件那圈东西"。有错误时说明文字自动让位 —— 两个都显示只会互相打脸。
