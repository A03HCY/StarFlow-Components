导航组件

5 个组件：Topbar / Sidebar / Tabs / Steps / PageHeader。这一批基本都是"容器 + 状态"，真正的复杂度在 Tabs 的 roving focus 和 Steps 的状态推导上。最后一节把它们拼成一个界面看。

组件 5 子组件 2 生效主题 — 依赖 0
01 / TOPBAR

Topbar

三段式：品牌 / 中间默认槽 / 右侧 slot="end"。默认 sticky + 半透明模糊，加 no-sticky 关掉。高度是 --sf-topbar-height。

Sidebar

03 / TABS

Tabs

标签条由 sf-tabs 渲染，面板是光 DOM 里的 <sf-tab>。左右键切换并自动激活，Home / End 跳首尾；只有当前标签是 tab 停靠点（roving tabindex）。

selected=0 构建成功率 98.2%，最近 7 天失败 4 次，集中在 nightly 分支。 今天有 3 条新活动：2 次部署、1 次回滚。 通知、权限、集成都在这里配置。

04 / STEPS

Steps

状态由父级的 current 推导后写到子级 data-status，子级只管画。"第几步"只有一个真相源，子级不用各自推断。连接线画在每一步内部。
