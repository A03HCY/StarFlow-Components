StarFlow Components basic · v0.1

基础组件

10 个不用上下文就能用的组件。每个组件自带第三层 token（只在需要的时候），样式里没有一处硬编码色值 —— 换主题时整页跟着走，组件一行代码都不用改。

组件 10 全局变量 104 生效主题 — 依赖 0
01 / BUTTON

Button

变体只换变量值，所以加一个 variant 不用写新的样式块。里面是原生 <button>，键盘、表单、读屏都是白送的。

variant 主要操作 次要操作 禁用
size 小号 默认
用法 <sf-button variant="ghost" size="sm">
02 / ICON BUTTON

IconButton

没有文字，所以 label 是必填的可访问名称 —— 少了它读屏只会念"按钮"。solid 变体用在有底色的工具条上。

size
solid
03 / BADGE

Badge

计数走实心底色（要跳出来），max 处理上限，dot 是给头像挂红点用的。没有自己的 token —— 默认色和 tone 用语义层就能表达。

count
dot
04 / TAG

Tag

不可交互的标签。可关闭时点击 × 派发 sf-remove，组件不自己删自己 —— 删标签通常还要同步改数据。

tone 默认 前端 已上线 待审核 已下线 描边
closable React TypeScript 待定
05 / AVATAR

Avatar

有 src 显示图片，图挂了或没 src 退回名字缩写（中文取后两字，英文取首字母）。不做 slot —— 要放图标直接用 div 更省事。

size
src
06 / TOOLTIP

Tooltip

悬停或聚焦 120ms 后出现，位置放不下会自动翻到对面。气泡 pointer-events: none，不然鼠标移上去就会闪。颜色是语义层取反（深底浅字），两套主题都成立。

placement 上 下 左 右
delay 无延迟 长文本
07 / POPOVER

Popover

锚点用 id 引用，浮层不参与触发器布局。点外面、按 Esc 都会关，Esc 还会把焦点还回触发器。用 fixed + --sf-z-*，容器 overflow 也不会裁掉。

anchored 筛选条件
筛选
应用 重置
08 / DROPDOWN

Dropdown

菜单项就是带 role="menuitem" 的普通元素，排版由组件的 ::slotted 负责。支持上下键 / Home / End / Esc，选中派发 sf-select。

menu 更多操作
重命名
复制一份
归档（无权限）
删除

Divider

有文字时两侧各一条线。没文字要隐藏第二条线 —— 两条线之间还留着 gap 的话，中间会缺一个口子，看起来像 3px 的粗线。

horizontal

vertical

Skeleton

尺寸走实例变量（--sf-skeleton-width/height/size）：占位块的大小天然由业务决定，预设几个档位反而都用不上。系统开了减少动效就停。
